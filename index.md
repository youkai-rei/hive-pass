# How to install

## Download

Download the modifed hive extension from here: [modifed hive extension](./extension.zip)


## Extract

Extract the downloaded zip file, it should give you a folder named `extension`.

## Install

1. Open your browser

2. Go to extensions tab

![extensions tab](./assets/extensions-tab.png "Go to Extensions tab")

3. Enable developer mode

![developer mode](./assets/dev-mode.png "Enable Developer mode")

4. Click on load unpacked

![load unpacked](./assets/load-unpack.png "Click on load unpacked")


5. Select the previously extracted `extension` folder

![select folder](./assets/select-folder.png "Select the extension folder")

## Verify

If the install was successful, you will see this small red icon in the extensions page

![verify](./assets/diditwork.png "Did it work?")
